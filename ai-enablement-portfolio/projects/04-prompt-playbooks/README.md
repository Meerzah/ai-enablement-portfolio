# Prompt Playbooks

> Ready-to-use prompt templates for non-technical teams using internal AI tools.

---

## Why this exists

The biggest barrier to AI adoption isn't access — it's knowing what to ask. These playbooks give teams a concrete starting point so they're not staring at a blank text box on day one.

Each playbook is written for a specific team's actual workflows, not generic AI tips.

## What makes a good prompt playbook

1. **Specific, not generic.** "Summarize this incident report and list action items" beats "summarize this document."
2. **Uses real team vocabulary.** Playbooks reference actual tool names, process names, and team structures.
3. **Shows the output format.** Include an example of what a good response looks like so people know what to expect.
4. **Short.** 8–12 prompts per team. More than that and nobody reads it.
