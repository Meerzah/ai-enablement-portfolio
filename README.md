### What "AI enablement" means in practice

Building AI tools is the easy part. The hard part is:

- Designing agents that non-technical users can actually operate
- Rolling them out without breaking people's workflows
- Instrumenting adoption so you know what's working
- Presenting outcomes to leadership in language they care about

Every project in this repo includes a `ROLLOUT.md` documenting how it was adopted, what friction looked like, and what metrics resulted.
